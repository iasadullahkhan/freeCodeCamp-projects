# Demographic Data Analyzer

A data analysis project that explores demographic trends using the 1994 U.S. Census dataset. Built with Pandas, this application performs data cleaning, filtering, aggregation, and statistical analysis to uncover meaningful insights related to education, income, occupation, and population demographics.

This project was completed as part of the freeCodeCamp Data Analysis with Python Certification.

## Key Analyses

* Race distribution within the dataset
* Average age of men
* Percentage of individuals holding Bachelor's degrees
* Income comparison across education levels
* Minimum working hours analysis
* High-income earners among minimum-hour workers
* Country-based income comparisons
* Most popular occupations among high-income individuals in India
