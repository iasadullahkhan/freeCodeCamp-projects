# Data Analysis with Python Projects

A collection of five data analysis projects completed as part of the freeCodeCamp Data Analysis with Python Certification. These projects demonstrate practical skills in data analysis, statistical computing, data visualization, time-series analysis, and predictive modeling using Python and industry-standard data science libraries.

## Projects Included

### 1. Mean-Variance-Standard Deviation Calculator

A statistical analysis application that uses NumPy to calculate:

* Mean
* Variance
* Standard Deviation
* Maximum Value
* Minimum Value
* Sum

for rows, columns, and the entire dataset within a 3×3 matrix.

**Technologies:** Python, NumPy

---

### 2. Demographic Data Analyzer

An exploratory data analysis project using the 1994 U.S. Census dataset to uncover demographic and income-related insights.

Key analyses include:

* Race distribution
* Average age statistics
* Education level analysis
* Income comparisons
* Country-based salary trends
* Occupation analysis

**Technologies:** Python, Pandas

---

### 3. Medical Data Visualizer

A healthcare data analysis and visualization project focused on identifying relationships between cardiovascular disease and various health indicators.

Features:

* BMI-based feature engineering
* Data normalization
* Outlier removal
* Categorical visualizations
* Correlation heatmaps

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn

---

### 4. Page View Time Series Visualizer

A time-series analysis project that examines historical page view data from the freeCodeCamp forum.

Generated visualizations include:

* Line charts
* Bar charts
* Box plots

The project highlights long-term growth trends and seasonal traffic patterns.

**Technologies:** Python, Pandas, Matplotlib, Seaborn

---

### 5. Sea Level Predictor

A predictive analytics project that analyzes historical global sea level data and forecasts future sea level rise through the year 2050 using linear regression models.

Features:

* Historical trend analysis
* Regression modeling
* Future forecasting
* Climate data visualization

**Technologies:** Python, Pandas, Matplotlib, SciPy
